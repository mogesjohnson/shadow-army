R-F-143 (P2): CH-1, how a CLI is found and started on Windows.
<<< OLD
never through a relative `PATH` entry. On Windows the current folder is never searched.
=== NEW
never through a relative `PATH` entry. On Windows the current folder is never searched. On Windows, a name is looked up in each absolute `PATH` entry with each extension of `PATHEXT` in order, never with none, and the first match wins. A `.cmd` or `.bat` CLI is started through `cmd.exe /d /s /c`, with every argument escaped for both `cmd.exe` and the program's own parser, as cross-spawn does; an argument with a line break goes through a file, as CH-2 does for the instructions. A unit test covers the escaping.
>>> END
